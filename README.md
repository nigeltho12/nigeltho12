I work in the space between the help desk and the security team: investigating phishing and alerts, managing identity and access, and hardening endpoints. This GitHub is where I build the rest of the loop: detection, response, offense, and forensics, practiced as one discipline instead of four.

I got into this field because I believe technology should protect people, especially the ones who can't afford an enterprise security team. Faith drives the mission. Technology is the tool.

## What I Do Day to Day

**Help Desk Engineer (Security-Embedded)**, insurance industry

- Investigate user-reported phishing and Datadog security alerts end to end, correlating evidence across Datadog, Wiz, Zscaler, Defender, Entra ID, and Purview, then hand documented findings to security engineering
- Manage identity and access in Entra ID and Microsoft 365 through just-in-time PIM roles
- Endpoint security and vulnerability management across Windows (Intune) and macOS (Jamf)
- IT custodian for audit-visible security platforms supporting ISO 27001 audits

> Nothing in this GitHub comes from my employer's environment. Everything public here is lab-built or generalized. Knowing where that line sits is part of the job.

## Where I'm Headed

Finishing my degree comes first. After that, I'm moving my study and work toward red and purple team: learning attacks well enough to execute them, then turning each one into a detection.

- **Offensive fundamentals:** building on eJPT toward deeper exploitation, Active Directory attacks, and adversary emulation
- **Detection engineering as code:** Sigma rules and Datadog Cloud SIEM rules in Terraform, mapped to MITRE ATT&CK, so every technique I practice ends with a detection
- **Threat hunting:** KQL hunts across Defender and Sentinel telemetry
- **Home lab:** building out an environment to run attacks and test detections end to end
